# DriveUp 🚗

DriveUp es una aplicación web full-stack para la gestión y alquiler de autos.  
Permite a los usuarios explorar un catálogo de vehículos, ver sus características, puntuar y marcar favoritos, además de reservar fechas.  
El sistema incluye un **panel de administración** para la gestión de autos, categorías, usuarios y reservas.

### 2. Instalación Local

Sigue estos pasos para ejecutar el proyecto en tu máquina.

#### Requisitos previos
* **Node.js** (v20+)
* **npm**
* **Java 17**
* **Maven**
* **PostgreSQL**

#### Backend (Carpeta `server`)
1. **Clona el repositorio**
    ```bash
    git clone https://github.com/JulyTAriza/DriveUp_AplicationProject.git
    cd server
    ```
2. **Configura la base de datos**
    * Crea una base de datos de PostgreSQL llamada `driveup_db`.
    * Configura las credenciales de tu base de datos en `src/main/resources/application.properties` o en tu archivo `.env`.
3. **Inicia el servidor**
    ```bash
    ./mvnw spring-boot:run
    ```

#### Frontend (Carpeta `client`)
1. **Instala las dependencias**
    ```bash
    cd client
    npm install
    ```
2. **Configura la URL de la API**
    * Crea un archivo `.env.local` y añade:
      ```ini
      NEXT_PUBLIC_API_URL=http://localhost:8080
      ```
3. **Inicia la aplicación**
    ```bash
    npm run dev
    ```

### 3. Endpoints de la API

#### 🔑 Autenticación
| Método | Endpoint | Descripción | Auth |
|--------|----------|-------------|------|
| POST   | `/auth/login` | Login de usuario | ❌ |
| POST   | `/auth/register` | Registro de usuario | ❌ |

#### 🚘 Autos
| Método | Endpoint | Descripción | Auth |
|--------|----------|-------------|------|
| GET    | `/autos` | Obtener todos los autos | ✅ |
| GET    | `/autos/{id}` | Obtener auto por ID | ✅ |
| GET    | `/autos/marca/{carBrand}` | Buscar autos por marca | ✅ |
| GET    | `/autos/nombre?name=...` | Buscar autos por nombre | ✅ |
| POST   | `/autos` | Crear nuevo auto (con imágenes) | ✅ (Admin) |
| PUT    | `/autos/{id}` | Actualizar auto (con imágenes) | ✅ (Admin) |
| PUT    | `/autos/{id}/caracteristicas` | Actualizar características | ✅ (Admin) |
| DELETE | `/autos/{id}` | Eliminar auto | ✅ (Admin) |

#### 🏷️ Categorías
| Método | Endpoint | Descripción | Auth |
|--------|----------|-------------|------|
| GET    | `/categorias` | Obtener todas las categorías | ✅ |
| GET    | `/categorias/{id}` | Obtener categoría por ID | ✅ |
| GET    | `/categorias/nombre/{name}` | Obtener categoría por nombre | ✅ |
| POST   | `/categorias` | Crear categoría | ✅ (Admin) |
| PUT    | `/categorias` | Actualizar categoría | ✅ (Admin) |
| DELETE | `/categorias/{id}` | Eliminar categoría | ✅ (Admin) |

#### 📅 Reservas
| Método | Endpoint | Descripción | Auth |
|--------|----------|-------------|------|
| GET    | `/reservas` | Obtener todas las reservas | ✅ |
| GET    | `/reservas/{id}` | Obtener reserva por ID | ✅ |
| GET    | `/reservas/user/{userId}` | Obtener reservas de un usuario | ✅ |
| POST   | `/reservas` | Crear nueva reserva (con ⭐=0 y ❤️=false) | ✅ |
| PUT    | `/reservas` | Actualizar reserva | ✅ |
| PUT    | `/reservas` | Actualizar estado (Pendiente/Confirmada/Cancelada) | ✅ |
| PUT    | `/reservas` | Actualizar puntuación ⭐ | ✅ |
| PUT    | `/reservas` | Actualizar favorito ❤️ | ✅ |
| DELETE | `/reservas/{id}` | Eliminar reserva | ✅ |

#### 👤 Usuarios (Admin)
| Método | Endpoint | Descripción | Auth |
|--------|----------|-------------|------|
| GET    | `/usuarios` | Obtener todos los usuarios | ✅ (Admin) |
| GET    | `/usuarios/{id}` | Obtener usuario por ID | ✅ (Admin) |
| POST   | `/usuarios` | Crear usuario | ✅ (Admin) |
| PUT    | `/usuarios` | Actualizar usuario | ✅ (Admin) |
| DELETE | `/usuarios/{id}` | Eliminar usuario | ✅ (Admin) |

### 4. Diagrama de Base de Datos

El modelo de datos de **DriveUp** incluye las siguientes entidades principales:  
- **Users** (con roles `ADMIN` y `USER`)  
- **Cars** (asociados a categorías y características)  
- **Categories** (organizan los autos)  
- **car_reservation** (relacionan usuarios con autos en fechas específicas, con estado, puntuación y favoritos)
